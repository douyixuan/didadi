# 本地未提交文档草稿恢复

状态：实施中。权威位置为本分支 Git 与对应 draft PR。用户本轮明确授权实现、测试、独立 review 和 CI；不合并、不接手 ADR41、不操作冻结的8806。

原范围依据：004工作区设计要求失败/冲突保留草稿；014历史浏览保留草稿；013导出完整未保存文本。025验收明确刷新/关闭恢复缺口，本轮授权补齐这一缺口，不引入协作 CRDT 或外部同步。

设计：Git 是已保存文档唯一权威。localStorage 只保存本 origin 下的用户ID、房间ID、固定demo.md、synthetic模式的未提交缓冲及base blob。每个编辑器实例独立记录，避免双标签互相覆盖；所有应用写删都在同一 Web Lock 中执行，缺该能力时明确提示并降级到页内编辑/导出。异步写入完成前提示保持页面打开；重开先读Git，显式选择恢复或丢弃。恢复前提示原base是否与当前Git不同，保存保留原base，只有用户显式确认已合并最新文本才采用当前base；当前脏稿或页内恢复稿存在时禁止替换，先保存或明确丢弃。无自动提交或任务重放。成功保存后仅清除本实例及明确恢复且未变化的旧记录，其他标签记录不删。失败/冲突保持。加载历史或最新不丢此前草稿。

容量：单草稿最多64KiB UTF-8，总记录最多16、该应用命名空间最多1MiB；不自动淘汰他人/旧草稿。超限、损坏或存储拒绝给出可见提示，继续页内编辑/导出。存储为本浏览器明文，可能被清理或同源代码读取，UI明确说明；不向网络发草稿，只有显式Save使用既有API。

实施：独立store+有意义的边界测试、Documents集成与跨重挂载/上下文/保存/冲突/不可用测试、文档。测试与生产构建后独立review；修复发现后提交draft、验证精确head CI；新端口8808，8806不改。真实GUI由独立任务验收，不能用组件测试冒充。
