# #13 编辑器逐块源码保留

状态：实施中。权威需求：GitHub Issue #13。用户于本次委派授权实现、独立 review、draft PR、合入与最终 main CI；#10/#11/#12/#18 归原执行流程，#14–16 不并行。

## 设计与验收口径

保留单一 ProseMirror 编辑表面，不将页面拆成互相独立的编辑器。保留原 Markdown 的顶层 AST 源码切片与空白分隔；未变节点直接输出原文，修改节点局部序列化。未知结构变成对应的可编辑源码原子块，front matter 折叠显示，GFM 表格可编辑。不执行 HTML，不上传图片。

固定语料在仓库中版本化，包含公开项目已固定 SHA 的真实 Markdown（记录来源与许可）及专门的中文、空白、围栏、列表和混合结构样例。统计：总文件数、可打开块编辑器数、整页 textarea 回退数/比例、无编辑保存字节变化、保存再开不稳定、真实编辑后的非目标行改写。语料不能证明普遍兼容性；Issue 里的 1010 文件基准没有提供固定清单，本次不冒称复现该统计。

每个语料都经真实编辑器解析与保存；真实编辑再保存验证源码切片，另对支持块、局部源码块、表格及重开做交互测试。未编辑行零改写按源码 diff（排除实际修改所在行）验证；块插入/删除/移动会改变其边界空行，另设语义与边界测试。解析失败必须显式报告，不静默丢失或伪装成功。

## 实现顺序

1. 创建原始源码映射、局部源码节点和保留序列化器；保留既有撤销/重做、组合输入、卸载不回写契约。
2. 固定真实语料和边界样例，运行真实 Milkdown roundtrip/编辑测试，CI 输出指标并对验收失败报错。
3. 独立代码 review、修正问题、本地界面验证与截图；保持 Vercel 暂停。
4. 检查最新归属/远端，draft PR；审查通过后按已授权范围集成，验证最终 main CI 再关闭 #13。

风险：Markdown 结构上下文会影响相邻块解析，重复块匹配与移动不能按纯文本随意配对；参考链接定义、HTML、空白和无结尾换行必须保留。不会仅用 no-op roundtrip 证明编辑后零噪音。

## 实施收敛

最终采用瞬态 WeakMap 节点来源映射，不向 Git 保存 editor JSON 或持久化 block IDs。raw 节点是同一 ProseMirror 的文本块，不嵌套 textarea；inline 未知结构保守提升为本顶层源码块。为保留 Markdown 无法表达的内部空段/列表边界，结构编辑会引入已说明的注释标记。新增 bounded 512-entry parse cache 加快逐块保存重开回归，不改变持久化权威。

固定语料为三个项目各八份真实文件（24）与九个自有边界样例（共33），另有独立交互/结构回归。语料 hash、来源 SHA 与许可均记录；测试不联网。CI 上传 JSON 报告。#13 中未固定版本/文件清单的 1010 文件测量不作为本次已复现证据。
